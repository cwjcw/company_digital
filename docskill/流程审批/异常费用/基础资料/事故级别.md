# 事故级别设计

中文表单：事故级别；英文表单：IncidentSeverityLevel；权限资源：`incident-severity-levels`。

## 表级能力与生命周期

- 表单前台缓存：无。前端事件：无（不建设通用事件功能；本需求金额/类型联动由本表受控逻辑处理）。多标签页：否。
- 通过KDOS `KdosDataTable`、统一FilterGroup/SqlFilterCompiler、服务端分页/排序/导出、字段和数据权限工作；默认不向普通用户授予新权限。
- 后端每次检查租户、操作、记录范围、字段授权和业务规则；修改/删除使用version，409拒绝并发覆盖，关键写入与审计同事务。
- 系统字段id(UUIDv7)、tenant_id、version默认隐藏、不可人工编辑；createdBy/createdAt/updatedBy/updatedAt沿用标准审计列，日期时间YYYY-MM-DD HH:mm:ss（Asia/Shanghai）。
- 所有本文件未使用的脱敏/公式/动态显隐/联动均在各字段明确写无。金额为精确numeric(18,2)，百分比为整数或numeric(4,1)，不使用浮点求和。

## 字段完整清单

#### 金额下限 / `amount_min`

- 是否允许重复：单个金额边界可重复；完整闭区间不得重复或重叠。

- 前端显示名称：金额下限；后端/API/数据库字段：`amount_min`。
- 字段类型及配置：数字，金额，2位小数，千分位；选项来源：不适用。
- 所属与子表关系：本表普通字段。
- 默认值及更新规则：空；不自动刷新。
- 可见/可编辑权限与角色：有read字段权限可见；有create/update字段权限可维护。
- 必填：是；重复及范围校验：允许相邻不相交区间；>=0，最多16位整数/2位小数；失败提示“金额下限不能小于0”；禁止闭区间重叠，报告冲突级别。
- 联动（来源、匹配键、触发、更新）：无。
- 公式：无；脱敏：无（仍受字段和记录权限限制）。
- 字段提示文字：无。
- 显隐条件与隐藏值处理：始终显示；不清空。

#### 金额上限 / `amount_max`

- 是否允许重复：单个金额边界可重复；完整闭区间不得重复或重叠。

- 前端显示名称：金额上限；后端/API/数据库字段：`amount_max`。
- 字段类型及配置：数字，金额，2位小数，千分位；选项来源：不适用。
- 所属与子表关系：本表普通字段。
- 默认值及更新规则：空；不自动刷新。
- 可见/可编辑权限与角色：有read字段权限可见；有create/update字段权限可维护。
- 必填：是；重复及范围校验：>=amount_min，最多16位整数/2位小数；错误提示“金额上限不能小于金额下限”；同租户未删除区间任意重叠拒绝。
- 联动（来源、匹配键、触发、更新）：无。
- 公式：无；脱敏：无（仍受字段和记录权限限制）。
- 字段提示文字：无。
- 显隐条件与隐藏值处理：始终显示；不清空。

#### 事故级别 / `severity_name`

- 是否允许重复：允许重复；关联ID、固定选项、区间/合计等其他业务校验仍适用。

- 前端显示名称：事故级别；后端/API/数据库字段：`severity_name`。
- 字段类型及配置：单选下拉框；选项来源：固定：特大、重大、严重、一般；普通成员不能新增。
- 所属与子表关系：本表普通字段。
- 默认值及更新规则：空；不自动刷新。
- 可见/可编辑权限与角色：有read字段权限可见；有create/update字段权限可维护。
- 必填：是；重复及范围校验：只能为固定四选项；同名不相交区间允许；任意级别区间重叠拒绝。
- 联动（来源、匹配键、触发、更新）：无。
- 公式：无；脱敏：无（仍受字段和记录权限限制）。
- 字段提示文字：无。
- 显隐条件与隐藏值处理：始终显示；不清空。

## 关系、操作与删除

- 内嵌子表单：无；关联子表：无。主单以severity_level_id外键引用，按confirmed_amount在有效闭区间匹配。
- 匹配表达式：amount_min <= confirmed_amount AND confirmed_amount <= amount_max。恰好一条才可提交；零条或多条提示“请管理员完善事故级别配置”。无预置金额区间。
- 新增/编辑/删除使用与类别相同的权限和ID+version规则；区间维护使用数据库租户advisory事务锁防并发重叠。被主单引用的级别阻止删除；被引用区间/名称禁止直接变更，以免历史等级解释变化，应新建未冲突区间。
- 模板、Excel导入预览/确认与服务端导出可用；错误行整批回滚；不向生产导入测试数据。
