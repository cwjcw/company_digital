## 页面、缓存与新鲜度

排名请求等待公共KdosDataTable首次回调后发出，使用真实用户页大小和筛选，不另起默认10行请求；展示固定前20名，金额降序、客户编号稳定次序，不允许客户端更换排名范围或排序。公共表格只承担布局、打印和查询状态展示。

Dashboard及排名查询键包含登录身份/权限上下文、数据revision及完整条件，业务结果保鲜5分钟。GET /finance/e10-orders/revision先校验现有大屏read权限，只返回当前租户最近成功财务批次、成功变更批次、客户映射版本及实时授权上下文的不可逆摘要，不返回金额或来源行；30秒内复用revision、最多每60秒轮询，并在窗口聚焦时检查。新的成功同步、客户分类或同账号授权变化使revision变化并重新查询；授权摘要改变时立即停止复用上一范围的占位结果，失败批次不会替换成功版本。客户分类保存和前端同步成功同时精确失效revision和相关金额查询。

统计大屏按亚洲/上海当前月份和当前年份初始化，也可切换全部年份或全部月份；不展示“刷新”按钮，数据按revision、重新进入和浏览器聚焦刷新。月度明细在用户具有年月字段读取权限且URL没有明确月份时默认当前业务月；用户清空月份后保留“全部月份”状态。月度页有独立`finance-e10-monthly` revision与授权缓存，不要求大屏权限。

Dashboard 的“订单日期”筛选绑定源E10真实`order_date`，独立于发生月份；该条件同时应用到金额汇总、排名和下钻。月度页将下钻订单日期条件合并入正式FilterGroup。订单日权限缺失时服务端拒绝该筛选。发生月份仍按生效月份筛选，跳转时保留两个日期维度。

月度列表在API层复用租户、字段权限、数据范围、上下文、搜索、高级过滤和稳定排序，在同一查询里物化匹配行，一次返回总数与当前页，避免原先COUNT与分页分别完整扫描复杂月度视图。金额以十进制文本返回保护精度；数值排序使用原始numeric而非文本。所有授权仍由每次API实时claims与Query Service执行，前端缓存不构成授权边界。
