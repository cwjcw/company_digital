# 待确认业务问题

1. 视觉要求中“产前评审交期小于等于当天且完成率小于 100%”同时描述为黄色和红色。当前实现采用：等于今天为黄色，早于今天为红色，完成率大于等于 100% 为绿色。
2. “新数据来源于上个月未完成品号，以及计划 9 月”中的“计划 9 月”缺少明确来源字段。当前自动滚动只复制上一有效月份的未完成品号；额外的未来计划来源需确认后接入。
3. 源表没有明确的图片二进制与业务品号映射。当前模型支持每个品号最多 2 个图片引用，上传压缩接口可在确认图片来源规则后补充。
4. PostgreSQL 已使用 `postgres` 角色完成真实 migration、seed 和接口联调。导入服务现已支持加密文件的本机 Excel 临时转换，并可接收一次性文档密码；若加密提供方禁止后台自动化，用户需在 Excel 中“另存为”标准 `.xlsx` 后再导入。
