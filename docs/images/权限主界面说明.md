1. 进入权限主界面的界面，参考“权限主界面.png”

2. 新增了权限后的权限主界面，参考“新增了权限后的权限主界面.png”

3. 在权限主界面，点击“添加成员”后出现的界面，参考包含“点击添加成员后”系列图片，业务含义是：有3种方式可以添加成员：整个部门添加，按角色添加，直接搜索或者选择成员添加。勾选任一上级部门时，默认同时选中该部门本身、其所有层级的子部门，以及直接或间接归属这些部门的全部成员；直接挂在该上级部门、未归属任何子部门的成员也必须包含，不能因没有子部门归属而漏选。部门选择和成员归属必须以稳定部门 ID 为准，部门名称只作显示；允许父子或不同分支同名，选择同名子部门时不得误选父部门的其他直属分支。旧通讯录若省略连续同名层级，须解析到最深的唯一部门节点，不能仅按名称或名称前缀匹配。

   在角色成员界面选择“按部门动态授权”时，只保存角色与部门稳定 ID，不把当前成员固化为角色成员快照。人员调入、新入职到该部门或其子部门后自动获得角色；调出、离职或停用后立即失去该部门带来的角色。直接选择个人产生的角色关系独立保留。

4. 添加成员并点击确认后，会出现权限编辑界面。参考“添加成员并点击确定后出现的界面.png”，其中，“对成员发布”下的虚线框，显示的是上一步添加成员操作里选择的部门/角色/成员，下方的“成员权限”方框（只能单选），显示的是：默认权限组（仅添加数据，添加并管理本人数据，添加并查看全部数据，管理全部数据，查看全部数据），自定义权限的入口。如果选择了默认权限组中的一个，点击确定就可以创建权限组了，回到“新增了权限后的权限主界面”

5. 点击上一步出现的“自定义”后，进入自定义权限界面，参考“自定义权限主界面.png”。“对成员发布”下的虚线框，显示的是上一步添加成员操作里选择的部门/角色/成员，下方的“成员权限”方框显示信息同第4点要求相同，但是默认显示“自定义”，在选中了自定义的情况下，下方出现自定义权限编辑，参考“自定义权限子界面”系列图片，一共4个选项。第一个是“名称信息”，填写权限组名称和描述信息。第二个“操作权限”，值得是能对表格做哪些操作。第三个“字段权限”，指的是对表格的哪些字段有权限。第四个“数据权限”。指的是对表格的哪些数据有权限，参考对应截图，通过两个组合来确定。第一个是满足条件的是方式，是全部满足，还是满足任意一个条件就可以。第二个是如果过滤数据。可以添加多个。可以参考“自定义权限子界面数据权限-筛选条件.png”，筛选的相关信息，我在kdos-form-platform有规定。
