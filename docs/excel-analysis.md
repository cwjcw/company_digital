## 数据类型与样本关系

- 两行月度数据的订单号均为字符串 `2026C235004`，证明一个订单可包含多个品号。
- 品号含连字符和斜杠，必须按字符串保存。
- Excel 日期以序列值出现，例如 46116；导入器按 Excel 日期纪元转为 `YYYY-MM-DD`，丢弃时间小数，避免本机时区偏移。
- 所需天数包含 `0.5`，数据库使用 `numeric(8,2)`。
- 状态样本同时出现 `Y`、数字和空值，保持可空字符串。
- 生产数量为 30、34；历史入库数和当天入库数为空，导入时保留 `null`，计算时才按 0 参与。
- 两个品号的关联信息均等于订单号和品号拼接；运行时仍以 `(period_id, order_id, item_number)` 唯一约束为准。
- 简图单元格缓存为 `#VALUE!`，不是图片，导入时置空并产生警告。
