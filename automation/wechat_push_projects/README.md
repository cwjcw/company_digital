# 企业微信推送项目

本目录是计划中心所有新增企业微信推送任务的统一入口。今后每个任务必须使用一个独立子文件夹，并在子文件夹内自带配置、状态文件、测试、运行说明和服务模板；不得把企业微信密钥、通讯录导出或业务图片提交到仓库。

统一约定：

- 企业微信和通讯录只能使用 `/data/automation/code/work/basci/basic_code` 中的 `WeChatPusher`。
- 默认命令只能预览，正式发送必须使用任务自己的显式发送参数。
- 测试接收人和正式接收人分开配置，首次上线先单人验证。
- 生成物写入仓库已忽略的 `data/` 目录。
- 周期任务启用前必须明确发送时间并完成单人实发验证。

当前任务：

- `equipment-governance-daily`：设备监测、责任人和培训条件的事业部日报。
