## 经真实数据库验证的关联

### 标准路线

`AA_Routing.id` ← `AA_Routing_b.idRoutingDTO`；`AA_Routing_b.idProcess` → `AA_Process.id`；路线工序顺序字段为 `AA_Routing_b.jobsequence`。对 1,056 条路线明细逐行匹配，路线表头和工序档案均为 1,056/1,056 匹配。样例行显示路线明细的 `jobsequence` 与工序档案名称能够对应。

### 品号、BOM版本和路线/BOM工序

- `AA_BOM.idinventory` → `AA_InventoryEntity.id`；直接核验 21,003/21,003 条 BOM 表头均有匹配存货 ID。BOM 版本用 `AA_BOM.version` 表示，同一品号有多版本时由 `idinventory` 聚合识别，`isDefaultBom` 指示默认版本。当前有 4 个存货各存在多条 BOM 版本；样例含版本 `01`（默认、启用）和 `A`（非默认、停用）。因此不能仅以品号编码或 BOM `code` 替代 ID 关联，也不能忽略版本及停用/默认状态。
- `AA_BOM.idrouting` → `AA_Routing.id`。当前 21,003 个 BOM 表头中有 246 个带路线，且 246/246 均匹配到实际路线；样例如存货 `GFF108KB-01`、BOM 版本 `01`、路线 `GY000031`。
- `AA_BOMProcess.idbom` → `AA_BOM.id`，`AA_BOMProcess.idProcess` → `AA_Process.id`，顺序字段为 `sequenceNumber`。本次 525 条 BOM 工序均匹配 BOM 和工序主档。对有路线的 BOM 按 `AA_BOMProcess.sequenceNumber = AA_Routing_b.jobsequence` 对齐后，525/525 行的工序 ID 与标准路线工序 ID 相同。
- `AA_BOMChild.idbom` 能匹配到 77,474/91,420 条现存 BOM 表头；其余 13,946 条未匹配的原因无法仅凭当前数据确认。子件 `idinventory` 全部匹配存货；`idprocess` 的 91,420 行均为 NULL。就当前数据而言，BOM 工序明细存于独立的 `AA_BOMProcess`，不能把 `AA_BOMChild` 当作 BOM 工序明细。
- `AA_InventoryEntity.idDefaultRouting` 的非空值 11,673 条均能连接 `AA_Routing.id`；真实样例也可通过此 ID 找到路线。但 CHM 对该字段的文字说明是“是否默认工艺路线”，与实际 ID 连接用途存在语义歧义，建议在 T+ 前台/供应商文档进一步确认显示语义。

### 生产加工单实际工序与报工

- `MP_ManufactureOrder.ID` → `MP_ManufactureOrder_b.idManufactureOrderDTO`：44,568/44,568 条明细匹配加工单表头；加工单明细 `id` → `MP_ManufactureOrder_Process.idManufactureOrderDetailDTO`：40,949/40,949 条实际工序匹配明细。
- 加工单明细记录其品号 `idinventory`、BOM `idbom`、版本 `bomVersion` 和路线 `idrouting`；实际工序行另存 `idProcess`、`sequencenumber`。实际工序的来源引用分两类：`IdRoutingDetail` → `AA_Routing_b.id` 为 40,345/40,345 匹配；`IdBomProcess` → `AA_BOMProcess.id` 为 604/604 匹配。两类来源记录的 `idProcess` 均与来源明细一致。因此实际加工单工序是独立快照/执行行，不能直接用最新标准路线代替。
- 在 40,345 条具有路线来源的实际工序中，工序 ID 均与来源路线明细一致；其中 8 条实际 `sequencenumber` 与来源 `jobsequence` 不同。当前证据能确认存在顺序差异，但不能判断这是合法人工调整还是历史数据异常。
- `MP_ManufactureReport.ID` → `MP_ManufactureReport_b.IdManufactureReportDTO`，报工明细 `ManufactureOrderProcessDetailId` → `MP_ManufactureOrder_Process.id`：当前 1,236/1,236 条报工明细均关联实际加工单工序；`IdRoutingDetail` 全部可匹配路线明细，`IdBomProcess` 未匹配到 BOM 工序记录。报工事实应以报工明细和实际加工单工序为依据，不应用标准配置回写覆盖。
